# My GeoDev Lab Africa Project

This project aims to identify wards in Bosso LGA that may have limited access to healthcare facilities. Using ward boundaries, health facility locations, and OpenStreetMap road data, the project will analyze the accessibility of health facilities and identify wards that are more than 5 km from a health facility.

This project is being developed as part of the GeoDev Lab Africa program.
